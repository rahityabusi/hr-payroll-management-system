# 🚀 SmallBizz Navigator – Enterprise Business Management System

A relational database management system designed to help small businesses streamline employee management, payroll, attendance tracking, leave management, project administration, and business operations through a centralized database platform.

---

# 📌 Overview

SmallBizz Navigator (SBN) is an enterprise business management system developed to simplify day-to-day business operations for small and medium-sized organizations.

The project provides a centralized database that manages employee information, attendance, payroll, departments, projects, leave requests, training records, customer information, and business reporting while maintaining data integrity through relational database design and SQL constraints.

The system was designed with scalability, security, and maintainability in mind to support growing businesses and evolving operational requirements.

# 📊 Database Design

The system includes a normalized relational database consisting of multiple interconnected entities including:

- Employee
- Department
- Designation
- Attendance
- Leave
- Payroll
- Employee Experience
- Education
- Training
- Address
- Project
- Tasks
- Owner
- Bank Information
- Settings

The database enforces referential integrity using Primary Keys and Foreign Keys to maintain data consistency.
